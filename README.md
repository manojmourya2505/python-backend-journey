I'm Manoj, a software engineer with 7+ years of experience building production apps and the Python backends that power them.

## Run any day's example

```bash
cd day01-intro-to-fastapi
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open http://127.0.0.1:8000/docs
